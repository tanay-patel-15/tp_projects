# Diabetes Risk Prediction

A machine learning project to predict diabetes risk using the Pima Indians Diabetes dataset.

## Features
- Multiple ML models (Random Forest, XGBoost, Logistic Regression)
- Interactive Streamlit dashboard for predictions
- Feature importance visualization

## Setup

```bash
# Install dependencies
pip install -r requirements.txt

# Run the web app
streamlit run app.py
```

## Project Structure
```
diabetes-prediction/
├── data/              # Dataset
├── notebooks/         # Jupyter notebooks for analysis
├── src/               # Source code modules
├── models/            # Saved trained models
├── app.py             # Streamlit web application
└── requirements.txt   # Python dependencies
```

## Dataset
[Pima Indians Diabetes Database](https://www.kaggle.com/uciml/pima-indians-diabetes-database) - 768 samples with 8 features.
